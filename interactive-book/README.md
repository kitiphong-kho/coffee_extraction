# ห้องเรียนการสกัดกาแฟ · ฉบับตำราเชิงโต้ตอบ

จัดทำโดย ศูนย์วิจัยพัฒนากาแฟคุณภาพ (Coffee Quality Research Center) มหาวิทยาลัยแม่ฟ้าหลวง

โฟลเดอร์นี้เป็นต้นฉบับ `index.html` ที่จัดรูปแบบใหม่เป็นตำราหลายหน้า เนื้อหา แบบจำลอง และภาพประกอบเดิมยังอยู่ครบ ส่วนไฟล์ `index.html` ที่ root ของ repo ไม่ได้แก้ไข

## เปิดดู

เป็นไฟล์ static ทั้งหมด ไม่ต้อง build เปิด `index.html` ผ่าน web server ใดก็ได้ เช่น

```
cd interactive-book
python -m http.server 8000
```

แล้วเข้า http://localhost:8000

## โครงสร้าง

| ไฟล์ | เนื้อหา |
| --- | --- |
| `index.html` | หน้าปก สารบัญ วิธีใช้ตำรา |
| `ch1.html` | บทที่ 1 หลักการสกัดกาแฟ |
| `ch2.html` | บทที่ 2 ห้องปฏิบัติการจำลอง + แบบฝึกหัดแก้รสชาติ |
| `ch3.html` | บทที่ 3 ปฏิบัติการชงแบบ Pour Over |
| `ch4.html` | บทที่ 4 แผนที่การชงกาแฟ |
| `ch5.html` | บทที่ 5 สูตรระดับโลก |
| `ch6.html` | บทเสริม 6 เมล็ดกาแฟและน้ำ |
| `appendix.html` | อภิธานศัพท์ บรรณานุกรม ที่มาและข้อจำกัด ผู้จัดทำ |
| `assets/book.css` | ระบบดีไซน์ทั้งหมด (สี ตัวอักษร โหมดมืด โหมดเน้นภาพ) |
| `assets/data.js` | โครงบท อภิธานศัพท์ บรรณานุกรม วัตถุประสงค์ สรุปท้ายบท แบบทดสอบ |
| `assets/book.js` | แถบบน สารบัญด้านข้าง ป๊อปอัปคำศัพท์/อ้างอิง แบบทดสอบ ความคืบหน้าการอ่าน การสลับโหมด |
| `assets/lab.js` | ห้องปฏิบัติการจำลองและแบบฝึกหัด (บทที่ 2) |
| `assets/brew.js` | ตัวจับเวลา กราฟการเทน้ำ สูตรพื้นฐานและสูตรระดับโลก (บทที่ 3, 5) |
| `assets/widgets.js` | การ์ดพารามิเตอร์ ตารางแผ่นกรอง วินิจฉัยอาการ คุณภาพน้ำ |

## สิ่งที่เพิ่มจากต้นฉบับ (ควรตรวจทาน)

- สรุปท้ายบท วัตถุประสงค์บทที่ 6 แบบทดสอบบทที่ 6 และข้อความ "สาระสำคัญ" สั้น ๆ ในโหมดเน้นภาพ
- รูปใหม่: แผนผังวิธีอ่านแผนภูมิ (รูปที่ 2.1) และแผนที่สูตร (อัตราส่วน × อุณหภูมิ ในโหมดเน้นภาพของบทที่ 5)
- นิยามคำศัพท์ที่ต้นฉบับไม่มี และรายละเอียดบรรณานุกรมของ Córdoba (2020), Gagné (2021), Hendon (2014)
- สูตร Scott Rao อ้าง *The Physics of Filter Coffee* (2021) ตามต้นฉบับ แต่หนังสือเล่มนี้เขียนโดย Jonathan Gagné
